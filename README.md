# Cultura-digital-semana-5
Actividad práctica de la semana 5

Este algoritmo en R es una aplicación de un modelo de regresión lineal simple aplicado al dataset "Women" propio de R; en este se realizaron:
- Carga y visualización de datos
- Identificación de valores atípicos mediante boxplots
- Creación del modelo
- Visualización de resultados mediante summary, test de Shapiro-Wilk, graficación de la ecuación de regresión lineal y plots
- Ajuste del modelo para que cumpla mejor los supuestos
- Visualización de resultados mediante summary, test de Shapiro-Wilk, graficación de la ecuación de regresión lineal y plots

El algoritmo del modelo ajustado ya es adecuador al cumplir más con los supuestos de regresión lineal.
